# 开发日志

记录《阿卡迪亚蝶梦》开发过程中的进展、踩坑与决策。按时间倒序排列，最新的在最上面。

内容分三类：

- **进展** —— 新完成的章节、场景或系统
- **踩坑** —— 遇到并解决的问题，含排查过程，避免以后重复掉进去
- **决策** —— 为什么选 A 不选 B，以及当时的取舍

## 撰写约定

新增一篇日志 = 在 `docs/devlog/posts/` 下新建一个 Markdown 文件，命名格式：

```
YYYY-MM-DD-简短英文标识.md
```

文件开头需要这几行 front matter：

```yaml
---
date: 2026-11-17
categories:
  - 进展
---
```

`categories` 建议从 **进展 / 踩坑 / 决策** 三者中选，也可按模块细分（如「房间系统」「剧本」）。写进 front matter 后，站点会自动生成分类页和按年份的归档，不用手工维护索引。
